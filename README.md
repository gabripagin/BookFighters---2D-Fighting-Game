# BookFighters---2D-Fighting-Game

BookFighters is a 2D fighting game developed as an independent project, featuring real-time combat, various characters from classic literature, and simple battle mechanics.


<img width="400" height="220" alt="image" src="https://github.com/user-attachments/assets/f768241d-0bb1-4a49-bca2-97a08e07057a" />

## About the project

This project involves the development of a 2D fighting game, exploring concepts such as programming, game development, combat logic, character control, and real-time interaction.

The project was developed with the aim of applying programming knowledge to create an interactive application, covering everything from the implementation of game mechanics to the interface and the management of match elements.

## Technologies

- Python
- Pygame
- Object-oriented programming
- Image and animation manipulation
- Collision detection

## Features

- Real-time 2D combat
- Characters from classic literature
- Attack and defense system
- Health bar
- Win/loss system
- Character movement
- Animations and visual effects
- Keyboard controls
